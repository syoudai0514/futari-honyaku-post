# ふたりの翻訳ポスト

夫婦向けメッセージPWA。感情のまま書き殴った言葉を、AIが本質(事実・気持ち・お願い)を保ったまま相手に届く言葉に翻訳し、送り手の承認を経て配達する。

## ステータス

**フェーズ0(デザインドキュメント)レビュー待ち。実装は未着手。**

- 📄 [フェーズ0 デザインドキュメント](docs/phase0-design.md)
  - 翻訳AIシステムプロンプト全文
  - 翻訳サンプル10組(不満6・感謝2・翻訳不能1・安全拒否1)
  - 安全分岐の判定方針とテストケース20件
  - APIキー2案比較 / アーキテクチャ / 画面遷移図 / 要確認事項

## 2大原則

1. **受信側に「元の荒れ度」を一切漏らさない** — 全メッセージ統一フォーマット。原文は翻訳後に破棄し、スキーマレベルで原文フィールドを存在させない
2. **届く言葉は「AIの言葉」でなく「本人の言葉」** — 翻訳文は送り手が確認・編集・承認して初めて送信される。自動送信は実装しない

## 予定スタック

Vite + React + TypeScript + Tailwind CSS + Zustand / PWA(GitHub Pages) / Cloudflare Workers(配達リレー) / Google Gemini API 無料枠(翻訳AI)
