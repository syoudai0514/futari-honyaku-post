# フェーズ1 夫婦テストチェックリスト

1台のiPhone(またはPC)で、実際の夫婦の言葉を使って試す。**フェーズ1は「翻訳の品質」と「書き殴りの心理的安全性」の審査がすべて。**

## 準備

1. `npm run dev` またはビルドをホスティングして開く
2. オンボーディングで名前・文体サンプル・無料Geminiキー([Google AI Studio](https://aistudio.google.com/apikey))を設定

## 送り手として(あなた・奥様それぞれで)

- [ ] 書き殴りボックスで、本当に遠慮なく書けたか。「消えます」を信じられたか
- [ ] 最近の実際の不満を書いて翻訳し、**深刻さが「軽い話」に薄まっていない**か(サンプル③の基準)
- [ ] 翻訳文を読んで「自分の言葉だ」と感じられたか。文体サンプルの口調が反映されているか
- [ ] AIが原文にない感謝・愛情・譲歩を**付け足していない**か
- [ ] 「もっと柔らかく」で深刻度まで薄まらないか。「もっとはっきり」で攻撃的にならないか
- [ ] 純粋な罵倒だけを書いたとき、翻訳されずに「一言足してほしい」と返ってくるか
- [ ] 感謝を書いたとき、ほぼ素通し(脚色なし)か。気恥ずかしい美文になっていないか
- [ ] 翻訳待ちの数秒、イライラした状態でも耐えられたか
- [ ] 承認画面の直接編集が自然に使えたか
- [ ] 説教された感じが1箇所でもなかったか(「どう変わった?」を開いたときも)

## 受け手として(自分宛てに届いたメッセージを相手のつもりで読む)

- [ ] 届いた文から「元は相当荒れていたのでは」と推測できてしまわないか
- [ ] 「AIっぽさ」「よそよそしさ」を感じないか
- [ ] リアクション4種は「返信できないときの逃げ道」として十分か

## 技術面

- [ ] 送信後にアプリを再起動しても、原文がどこにも残っていない(自動テストでも担保済み)
- [ ] iPhone Safariで「ホーム画面に追加」→スタンドアロン起動できるか
- [ ] キーボードのマイク(音声入力)で書き殴りが快適か
- [ ] 無料枠の上限(10回/分)に当たったとき、案内メッセージが出て復帰できるか

## 記録すること

- 「薄まった」「本人っぽくない」と感じた翻訳は、**原文と翻訳文のペアをメモ**(プロンプト改善の材料。原文は自動保存されないため手動で)
- フェーズ2に進む判断基準: 夫婦2人とも「これなら相手に送ってもいい」と思える翻訳が7割を超えること
